# 🔲 Générateur de QR Code avec Logo

Un générateur de QR code simple et élégant permettant d'ajouter un logo personnalisé au centre du QR code.

![Version](https://img.shields.io/badge/version-1.0.0-blue)
![Licence](https://img.shields.io/badge/licence-Open%20Source-green)
![HTML](https://img.shields.io/badge/HTML-5-orange)

## ✨ Fonctionnalités

- 📱 **Génération de QR codes** à partir de texte ou URL
- 🎨 **Logo personnalisable** au centre du QR code
- 📏 **Taille ajustable** du QR code (200-500px)
- 🔧 **Contrôle de la taille du logo** (8-25%)
- ⬇️ **Téléchargement** en format PNG
- 🎯 **Interface moderne** et responsive
- ✅ **Niveau de correction d'erreur élevé** pour garantir la lisibilité

## 🚀 Utilisation

1. **Téléchargez** le fichier `qrcode-generator.html`
2. **Ouvrez-le** dans votre navigateur web
3. **Entrez** votre texte ou URL
4. **Uploadez** un logo (optionnel)
5. **Ajustez** les paramètres selon vos besoins
6. **Cliquez** sur "Générer le QR Code"
7. **Téléchargez** votre QR code !

## ⚠️ Recommandations importantes

> **Attention** : Pour garantir une lecture optimale du QR code :
> - Gardez la taille du logo entre **15% et 20%**
> - Au-delà de 20%, la lecture peut être compromise
> - Testez toujours votre QR code avant impression

## 🛠️ Technologies utilisées

- **HTML5** / **CSS3** / **JavaScript**
- **QRCode.js** - Bibliothèque de génération de QR codes
- **Canvas API** - Pour la manipulation d'images

## 📋 Prérequis

- Un navigateur web moderne (Chrome, Firefox, Safari, Edge)
- Connexion Internet (pour charger la bibliothèque QRCode.js)
